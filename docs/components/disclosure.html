Disclosure

Content that expands in place.

Expandable content

Can I use my own colors?

Yes. Define the theme tokens in your application stylesheet.

<%= ui_disclosure title: "Can I use my own colors?" do %>
  <p class="text-sm text-ink-2">Yes. Define the theme tokens in your application stylesheet.</p>
<% end %>

API reference

Helpers render semantic HTML and include their interaction wiring. Pass native attributes through class:, data:, aria: and the usual Rails options. Blocks use captured ERB content.

Styling and extension

Use class: to merge utilities, native attributes for application behavior, and theme tokens for the shared palette. For custom markup, the advanced class helpers expose the same styles, including glass surfaces and class merging.
