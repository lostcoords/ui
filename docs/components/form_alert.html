Components / Form alert

Form alert

Feedback inside a form.

Usage

After the one-time setup, call the helper directly from ERB. No component import is needed.

erb 
<%= ui_form_alert "That name is already taken." %>

Examples

Error#

That name is already taken.

erb 
<%= ui_form_alert "That name is already taken." %>

Notice#

Changes saved.

erb 
<%= ui_form_alert "Changes saved.", tone: :notice %>

API reference

Helpers render semantic HTML and include their interaction wiring. Pass native attributes through class:, data:, aria: and the usual Rails options. Blocks use captured ERB content.

ui_form_alert

ui_form_alert(message, tone: :error, **attributes)
InputDefaultValues
messageRequired—
tone:error:error · :notice
attributes{}Native HTML attributes; class:, data: and aria: merge with defaults

Styling and extension

Use class: to merge utilities, native attributes for application behavior, and theming guide for the shared palette. For custom markup, the advanced class helpers expose the same styles, including glass surfaces and class merging.
