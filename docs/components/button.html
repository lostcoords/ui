Button

Actions, links and native Rails forms.

Usage

After the one-time setup, call the helper directly from ERB. No component import is needed.

<%= lc_button "Create project" %>

Examples

Default#

<%= lc_button "Create project" %>

Variants#

<%= lc_button "Primary" %>
<%= lc_button "Secondary", variant: :secondary %>
<%= lc_button "Outline", variant: :outline %>
<%= lc_button "Ghost", variant: :ghost %>
<%= lc_button "Glass", variant: :glass %>
<%= lc_button "Delete", variant: :destructive %>

Glass over content#

Use glass for controls floating over content. Its translucency is subtle on a flat background.

<div class="grid w-full gap-4">
  <p class="text-sm text-muted-foreground">Use glass for controls floating over content. Its translucency is subtle on a flat background.</p>
  <div class="relative isolate h-64 overflow-hidden rounded-3xl bg-linear-to-br from-success/40 via-warning/40 to-primary/30">
    <div class="absolute inset-0 grid grid-cols-3 gap-4 p-6" aria-hidden="true">
      <div class="rounded-3xl bg-background/40"></div>
      <div class="translate-y-12 rounded-full bg-success/40"></div>
      <div class="-translate-y-8 rounded-3xl bg-warning/50"></div>
    </div>
    <div class="absolute inset-x-6 bottom-6 flex flex-wrap justify-center gap-3">
      <%= lc_button "Save", variant: :glass, icon: "bookmark" %>
      <%= lc_button "Share", variant: :glass, icon: "arrow-up-tray" %>
    </div>
  </div>
</div>

Sizes#

<%= lc_button "Small", size: :sm %>
<%= lc_button "Default" %>
<%= lc_button "Large", size: :lg %>

With an icon#

<%= lc_button "Create project", icon: "plus" %>
<%= lc_button "Continue", icon: "arrow-right", icon_position: :end, variant: :secondary %>

Custom icons and content#

For custom SVGs and spinners, use data-icon="inline-start" or data-icon="inline-end". The button reduces padding on that edge for optical balance. The icon: option sets this automatically.

<%= lc_button variant: :secondary do %>
  <%= lc_icon "arrow-down-tray", options: {
    "aria-hidden": true,
    "data-icon": "inline-start"
  } %>
  Download report
<% end %>

<%= lc_button disabled: true, aria: { busy: true } do %>
  <%= lc_spinner size: :sm, label: nil,
      data: { icon: "inline-start" } %>
  Loading report…
<% end %>

Loading#

<%= lc_button disabled: true, aria: { busy: true } do %>
  <%= lc_spinner size: :sm, label: nil, data: { icon: "inline-start" } %>
  Saving…
<% end %>

Disabled#

<%= lc_button "Unavailable", disabled: true %>

As a link#

Browse components 
<%= lc_button_link_to "Browse components", "/components/button.html", variant: :secondary %>

HTTP actions#

<%= lc_button_to "Archive project", "/projects/42", method: :delete, variant: :destructive, form: { data: { turbo_confirm: "Archive this project?" } } %>

Icon buttons#

<%= lc_icon_button "Add project", icon: "plus" %>
<%= lc_icon_button "Settings", icon: "cog-6-tooth", shape: :square %>
<%= lc_icon_button "Search", icon: "magnifying-glass", size: :sm %>
<%= lc_icon_button "Close", icon: "x-mark", size: :lg %>

The examples also use lc_spinner. Each is documented on its own page.

Styling and extension

Use class: to merge utilities, native attributes for application behavior, and the theming guide for the shared palette. For custom markup, the advanced class helpers expose the same styles, including glass surfaces and class merging.
