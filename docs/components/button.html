Components / Button

Button

Actions, links and native Rails forms.

Usage

After the one-time setup, call the helper directly from ERB. No component import is needed.

erb 
<%= ui_button "Create project" %>

Examples

Default#

erb 
<%= ui_button "Create project" %>

Variants#

erb 
<%= ui_button "Primary" %>
<%= ui_button "Secondary", variant: :secondary %>
<%= ui_button "Ghost", variant: :ghost %>
<%= ui_button "Delete", variant: :destructive %>

Sizes#

erb 
<%= ui_button "Small", size: :sm %>
<%= ui_button "Default" %>
<%= ui_button "Large", size: :lg %>

With an icon#

erb 
<%= ui_button "Create project", icon: "plus" %>
<%= ui_button "Continue", icon: "arrow-right", icon_position: :end, variant: :secondary %>

Custom icons and content#

For custom SVGs and spinners, use data-icon="inline-start" or data-icon="inline-end". The button reduces padding on that edge for optical balance. The icon: option sets this automatically.

erb 
<%= ui_button variant: :secondary do %>
  <%= heroicon "arrow-down-tray", options: {
    "aria-hidden": true,
    "data-icon": "inline-start"
  } %>
  Download report
<% end %>

<%= ui_button disabled: true, aria: { busy: true } do %>
  <%= ui_spinner size: :sm, label: nil,
      data: { icon: "inline-start" } %>
  Loading report…
<% end %>

Loading#

erb 
<%= ui_button disabled: true, aria: { busy: true } do %>
  <%= ui_spinner size: :sm, label: nil, data: { icon: "inline-start" } %>
  Saving…
<% end %>

Disabled#

erb 
<%= ui_button "Unavailable", disabled: true %>

As a link#

Browse components
erb 
<%= ui_button_link_to "Browse components", "/components/button.html", variant: :secondary %>

HTTP actions#

erb 
<%= ui_button_to "Archive project", "/projects/42", method: :delete, variant: :destructive, form: { data: { turbo_confirm: "Archive this project?" } } %>

Styling and extension

Use class: to merge utilities, native attributes for application behavior, and theming guide for the shared palette. For custom markup, the advanced class helpers expose the same styles, including glass surfaces and class merging.
