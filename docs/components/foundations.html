Foundations

Typography, spacing and reading rhythm shared by every app.

Choose a role, then arrange the content

Text styles pair size, line height, weight and tracking. Heading level describes the document structure; size: describes its appearance. Parents set space between children with stacks, inline groups and sections. Use <code> for inline references with a monospace font and subtle background.

Use reading styles for articles

lc_prose styles rendered HTML with a 65ch reading measure, 1.75 line height and proportional block spacing. Enable @plugin "@tailwindcss/typography"; in the host Tailwind input. The standalone Rails CLI includes the plugin. Mark embedded controls or cards not-prose to keep their component styles.

Theme colors

These eleven colors are the everyday theme settings. Defaults work without overrides. Names describe their purpose: bg-muted for a card, text-muted-foreground for a hint, border-border for a divider. Values below follow the selected palette and light or dark mode.

Change --primary to update actions, links, selection and focus together. Soft backgrounds for primary and status colors are generated automatically. See the theming guide for examples.

Typography, spacing and appearance

Use these settings when you need to change typography, spacing or rendering details. Set a property on a page wrapper for a local change, or on :root for the whole app. Load overrides after the engine stylesheet. Japanese text follows lang="ja". 

.report-page {
	--primary: oklch(46% 0.14 155);
	--lc-inset: 1.5rem;
	--lc-density: 1.125;
	--text-title: 2rem;
}

Feedback follows the action

Buttons respond to hover and press automatically. Copy buttons transition their label and icon after the clipboard write succeeds. The same button keeps focus and reserves room for every label, so nearby content stays still. Try the controls below with a mouse, keyboard, or touch.

Share timing across your app

Override these CSS variables after the engine import, or on a container to tune one area. Feedback duration controls the visual transition. The copy button's reset_after: controls how long confirmation remains visible.

--lc-motion-quick
140ms · icon controls
--lc-motion-control
180ms · buttons
--lc-motion-feedback
160ms · label and icon swaps
--lc-press-scale
0.96 · pressed icon controls
--lc-ease-out
Shared control easing

Respect reduced motion

When the operating system requests reduced motion, controls skip lift and press scaling, and copy feedback changes immediately. Labels, icons, focus, and success announcements still work. Other component animations use the theme's existing reduced-motion handling.

Connect application actions to real results

Your application owns saving and submitting. Show loading while work is pending, success after it finishes, and an error when it fails. Compose lc_button with lc_spinner and aria-busy for loading feedback. Keep timings in CSS and expose interaction state through data or ARIA attributes in your own controllers. Blocks reuse the library's controls and supply their application behavior.

Usage

After the one-time setup, call the helper directly from ERB. No component import is needed.

<div class="grid gap-5">
  <%= lc_heading "Weekend in Kyoto", level: 2, size: :title %>
  <%= lc_heading "Shared expenses", level: 3, size: :heading %>
  <%= lc_heading "Dinner with friends", level: 4, size: :subheading %>
  <%= lc_text do %>Use <code>lc_stack</code> to keep related content together.<% end %>
  <%= lc_text "Add a receipt or a short note for your group.", size: :small, tone: :muted %>
  <%= lc_text "Updated a few minutes ago", size: :caption, tone: :muted %>
</div>

Make room for the trip

A shared plan is easier to follow when each idea has room to breathe. Keep the essentials close and give a new topic a little more space.

Start with one clear decision, name the plan kyoto-weekend, then choose what comes next.

  • Choose a place to stay.
  • Set aside time for a slow morning.
  • Leave an afternoon open.

The best part of a plan is the space it leaves for a surprise.

Styling and extension

Use class: to merge utilities, native attributes for application behavior, and the theming guide for the shared palette. For custom markup, the advanced class helpers expose the same styles, including glass surfaces and class merging.
