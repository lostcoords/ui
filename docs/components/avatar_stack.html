Components / Avatar stack

Avatar stack

A group of people in a compact row.

Grouped

AL AN MO +2 
<div class="<%= avatar_stack_class %>">
  <div class="<%= avatar_stack_row_class %>">
    <% { "AL" => "sky", "AN" => "leaf", "MO" => "berry", "+2" => "gold" }.each do |initials, color| %>
      <span class="<%= avatar_class %>" style="background-color: var(--<%= color %>)"><%= initials %></span>
    <% end %>
  </div>
</div>

Compact

AL AN MO +2 
<div class="<%= avatar_stack_class(compact: true) %>">
  <div class="<%= avatar_stack_row_class %>">
    <% { "AL" => "sky", "AN" => "leaf", "MO" => "berry", "+2" => "gold" }.each do |initials, color| %>
      <span class="<%= avatar_class %>" style="background-color: var(--<%= color %>)"><%= initials %></span>
    <% end %>
  </div>
</div>
