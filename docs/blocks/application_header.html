Blocks/Application header

Application header

A glass header with navigation, an account menu and room for your brand.

Open preview ↗

Interact with the example above, or open it in a full window.

Make it yours

After setting up the library, copy the example files into your app and adapt the content. These are composition references, with no block API to install or import.

Load the copied stylesheet from your application layout. Place the controller in your Stimulus controller directory and register it using your app's usual loading convention.

Replace the sample brand, links and account actions with your application's content.

Keep navigation destinations as links and account actions in the menu. The header's layout and scroll behavior live in the example files.

  opacity: 1;

  }
}

app/javascript/controllers/blocks_header_controller.js

javascript 
import { Controller } from "@hotwired/stimulus"

export default class extends Controller {
  connect() {
    this.scroll()
  }

  scroll() {
    this.element.toggleAttribute("data-scrolled", window.scrollY > 8)
  }
}
