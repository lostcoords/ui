Components

Browse every component in the library, with examples and API reference.

  • 01 Alert Inline feedback, warnings and errors.
  • 02 App header A sticky glass header with your brand, navigation and actions.
  • 03 Avatar Initials or an image representing a person.
  • 04 Badge Labels, counts and status.
  • 05 Breadcrumb The path to the current page.
  • 06 Button Actions, links and native Rails forms.
  • 07 Card Surfaces for related content.
  • 08 Checkbox Native checkboxes with labels and hints.
  • 09 Code block Source snippets with copying, optional highlighting and collapsible long content.
  • 10 Collapsible Content that expands in place.
  • 11 Copy button Copy text or a live field value with animated confirmation and accessible feedback.
  • 12 Description list Labelled details, such as record properties.
  • 13 Dialog A focused task, with a sheet layout on phones.
  • 14 Dock A floating bar of primary destinations and quick actions at the bottom of a phone screen.
  • 15 Docs shell A documentation layout: sidebar, page and an "On this page" column, with a menu on phones.
  • 16 Emoji picker Search, categories and skin tones.
  • 17 Empty state A starting point when there is no content yet.
  • 18 Field Labels, controls and validation that stay connected.
  • 19 Glass A translucent surface for controls floating over content.
  • 20 Icon badge A small container for a symbol.
  • 21 Input Native single-line input.
  • 22 Keyboard shortcut Page-wide keys that focus or press an element, and the hints that show them.
  • 23 Link Inline text links with a visible underline.
  • 24 List group Grouped rows of settings, with a heading and footnote.
  • 25 Menu Actions in a floating panel.
  • 26 Native select Native options with consistent sizing.
  • 27 Nav list Navigation that marks the current page: sidebars, page contents, tab rows and a phone dock.
  • 28 Pager Previous and next links between pages in a sequence.
  • 29 Popover Content anchored to a trigger.
  • 30 Radio One choice from a short list.
  • 31 Search A full-screen search with grouped results.
  • 32 Skeleton A placeholder while content loads.
  • 33 Skip link Lets keyboard users jump past repeated navigation.
  • 34 Spinner An action in progress.
  • 35 Switch An on or off setting that submits like a checkbox.
  • 36 Table Native tables with clear headers and subtle row dividers. Keep captions, headers and scroll containers in the view.
  • 37 Table of contents An "On this page" list that marks the section the reader has scrolled to.
  • 38 Tabs Panels of related content behind one tab list, with arrow key navigation.
  • 39 Textarea Room for more than one line.
  • 40 Toast Brief feedback after an action.
  • 41 Toggle Pressed controls, filter links and radio choices.
  • 42 Toggle group Mutually exclusive choices with keyboard navigation and form values.
  • 43 Tooltip A short hint on hover and keyboard focus.
