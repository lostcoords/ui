Theming

Start with the Lostcoords light and dark theme. Override the values you want to change.

Start with the default theme

The engine stylesheet includes colors, system fonts, shadows, glass effects and motion settings. After installation, every component has a working theme. No token file is required.

Change your colors

A design token is a named CSS value shared by components. Add overrides after the engine import in app/assets/tailwind/application.css. Override only the values you need.

CSS variablesControls
--paper, --paper-2, --paper-3Page backgrounds and layered surfaces
--ink, --ink-2, --ink-3Primary, secondary and muted text
--sky, --sky-deep, --sky-softPrimary actions, hover states and subtle highlights
--ink-on-accentText on primary actions
--accentLinks and accents. Defaults to the primary hover color.
--hairlineBorders and dividers
--leaf, --gold, --berrySuccess, warning and error tones, each with a matching -soft value

For green primary actions, set the three primary colors for both themes. The existing sky names work with any hue.

css 
:root {
  --sky: oklch(52% 0.14 155);
  --sky-deep: oklch(46% 0.14 155);
  --sky-soft: oklch(96% 0.02 155);
}

html[data-theme="dark"] {
  --sky: oklch(75% 0.14 155);
  --sky-deep: oklch(70% 0.14 155);
  --sky-soft: color-mix(in oklab, var(--sky) 18%, var(--paper));
}

The theme maps these values to Tailwind utilities such as bg-paper, text-ink and bg-sky. Use the same utilities in your own markup to match the components. When you change a palette, check text and focus contrast in both themes.

Switch to dark mode

Set data-theme="dark" on <html> to activate the dark palette and Tailwind's dark: variant.

html 
<html lang="en" data-theme="dark">

Remove the attribute, or set it to light, for the light theme. Your app controls the switch, saved preference and system preference. Set the attribute before the first paint to avoid a theme flash.

Choose your fonts

The default theme uses system fonts. Load your own font in your app, then override the body and heading families.

css 
:root {
  --f-body: "Inter", ui-sans-serif, system-ui, sans-serif;
  --f-display: "Inter", ui-sans-serif, system-ui, sans-serif;
}

Use --f-mono for code. The default theme uses --f-japanese on pages with lang="ja". If you override the body and heading fonts globally, add your Japanese font overrides under html:lang(ja) too. See Foundations for text roles and spacing overrides.

Adjust corners and shadows

Set Tailwind's radius variables on body to adjust rounded controls and cards. Buttons that use rounded-full keep their pill shape. Override --shadow to change the shared surface shadow.

css 
body {
  --radius-xl: 0.625rem;
  --radius-3xl: 1rem;
}

:root {
  --shadow: 0 2px 12px rgb(0 0 0 / 0.08);
}

html[data-theme="dark"] {
  --shadow: 0 2px 12px rgb(0 0 0 / 0.3);
}

For one component, use its class: attribute, such as class: "rounded-lg shadow-none".

Advanced theme values

Glass surfaces, pill effects, overlay scrims, animation timing and stacking order have defaults too. Override these only when you need a different treatment. Reduced motion preferences shorten animations automatically.
